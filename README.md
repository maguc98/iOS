# POP CAM 📸

一款以多巴胺配色为视觉语言的原生 iOS 相机应用。

## 产品方向

POP CAM 把轻快、年轻、简单的体验放在第一位：打开即拍，滤镜即时可选，操作不打扰取景。

## 技术栈

- Swift 5
- SwiftUI
- AVFoundation（相机采集、拍照、闪光灯、前后摄像头）
- Core Image（照片滤镜与图像调整）
- Photos（保存到系统照片图库）

## 当前版本

**0.1.0 · Foundation**

第一阶段建立原生工程、相机预览与拍摄流程、滤镜选择、照片预览及保存能力。后续逐步加入定时拍摄、曝光和变焦控制、网格线、更多胶片效果。

## 开发

使用 Xcode 打开 `POP CAM.xcodeproj`，选择 iPhone 模拟器或已连接的设备运行。

真实相机预览、闪光灯和拍摄能力需要在真机上验证。
